Technology Stack

How We Built It

Enterprise-grade technology stack designed for scalability, security, and real-time performance.

01

Next.js 15 + React 19

Full-stack framework with App Router, SSR, and TypeScript.

02

Google Gemini AI (gemini-3.6-flash)

Multimodal AI — reads PDFs natively. Generates scores, skill gaps, action plans.

03

Supabase (PostgreSQL + pgvector)

Database with RLS, realtime, file storage, and vector embeddings.

04

Google text-embedding-004

768-dimensional vectors for semantic job matching beyond keywords.

05

Supabase Auth + Row-Level Security

Role-based access. Students can ONLY see their own data.

06

Vercel + Tailwind + shadcn/ui

Deployed with cron jobs. Premium dark-mode glassmorphism UI.

AI Gap Analyzer — How It Works

1

Student Uploads PDF Resume

Drag-and-drop. Stored in Supabase Storage's encrypted bucket.

2

Selects Target Company

Picks from pre-ingested corporate JDs or pastes a manual JD.

3

Gemini Reads the PDF Natively

PDF → Base64 → Gemini as multimodal input. No text extraction needed.

4

AI Returns Structured JSON

Match Score, Missing Skills, 48-Hour Action Plan — saved to DB for admin analytics.

🎤 RAG Architecture

AI Interview — Not Generic. Real.

Questions from actual corporate JDs, not a static question bank.

❌ Traditional Approach

  • Generic 500+ pre-written question banks
  • No connection to the specific company's needs
  • Students memorize instead of understanding
  • Same questions for all companies

✅ Our RAG Approach

  • Queries corporate_jobs table for real JD
  • Gemini generates company-specific questions
  • Supports voice & text chat modes
  • Graceful fallback if JD not in database
RAG Flow
Pick role → DB lookup → Real JD → Gemini → Company-specific Q&A
